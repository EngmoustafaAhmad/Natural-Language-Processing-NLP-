# 🔀 Ambiguity in Morphology (الغموض الصرفي)

## 📌 Definition
Ambiguity occurs when a word has **multiple valid analyses (meanings or structures)**.

---

## 🧠 Example


unionizable


Possible segmentations:
- union + ize + able  
- un + ion + ize + able  

👉 Both are valid → this is **Morphological Ambiguity**

---

## ⚠️ Problem

In systems like FST:
- Each path = different meaning  
- Hard to determine the correct one  

---

## ✅ Solutions

1. **First Solution**
   - Take the first valid result  

2. **All Solutions**
   - Return all possible parses  

3. **Context-Based**
   - Use surrounding words to choose the best meaning  

---

## 🚀 Key Insight

Ambiguity is a major challenge in NLP and requires **context or probability models** to resolve.
