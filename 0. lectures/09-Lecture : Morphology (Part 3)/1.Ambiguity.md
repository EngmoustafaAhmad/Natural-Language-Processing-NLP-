🔀 1. Ambiguity in Morphology (الغموض الصرفي)
📌 يعني إيه؟

لما الكلمة يكون لها أكثر من تحليل (معنى أو تركيب).

مثال:
unionizable

ممكن تتقسم بطريقتين:

union + ize + able
un + ion + ize + able

👉 الاتنين صح → ده اسمه Ambiguity

💡 المشكلة:

في الأنظمة (زي FST):

كل مسار = معنى مختلف
فمش عارف نختار الصح بسهولة
✅ الحلول:
نختار أول حل
نرجع كل الحلول
نستخدم context (الجملة) لاختيار الأفضل
🔍 2. Stemming vs Full Morphological Analysis
🟢 Stemming (تبسيط)
بنجيب جذر الكلمة فقط
بدون تفاصيل
مثال:
playing → play

👉 سريع لكن مش دقيق

🔴 Full Morphological Analysis (تحليل كامل)
بنطلع:
الجذر
نوع الكلمة
الزمن / العدد / ...
مثال:
playing → play + V + ING

👉 أدق لكن أبطأ

⚖️ الفرق:
Feature	Stemming	Full Analysis
الدقة	قليلة	عالية
السرعة	سريعة	أبطأ
الاستخدام	Search Engines	NLP Systems
⚙️ 3. The Porter Stemmer
📌 هو إيه؟

أشهر خوارزمية Stemming

👉 بتشيل الـ affixes باستخدام قواعد

💡 مثال قواعد:
ING → ""
playing → play
SSES → SS
grasses → grass
IZATION → IZE
computerization → computerize
⚠️ ملاحظات:
مش محتاج dictionary
سريع جدًا
ممكن يطلع كلمة مش حقيقية
لكن ده عادي في البحث
🌍 4. Arabic Morphology (الصرف في العربي)
📌 ليه مهم؟

العربي معقد جدًا مقارنة بالإنجليزي

💡 الخصائص:
Prefixes: (و، ف، ب...)
Suffixes: (ها، هم...)
Root system (جذور)
زمن + عدد + جنس
🔥 مثال:
فسيأكلونها

تعني:

"and they will eat it"
📊 التحليل:
ف → and
س → future
يأكل → eat
ون → plural
ها → it

👉 كلمة واحدة = جملة كاملة 😅
