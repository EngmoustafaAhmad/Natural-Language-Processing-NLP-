# ⚙️ The Porter Stemmer

## 📌 Definition
A popular **stemming algorithm** developed by Porter (1980).

---

## 🧠 How It Works

- Uses rule-based transformations
- Removes affixes step by step
- Does NOT use a dictionary

---

## 🔧 Example Rules

| Rule | Example |
|------|--------|
| ING → "" | playing → play |
| SSES → SS | grasses → grass |
| IZATION → IZE | computerization → computerize |
| IZE → "" | computerize → computer |

---

## ⚠️ Notes

- Very fast
- No lexicon required
- Output may NOT be a real word

---

## 🎯 Use Case

Mainly used in:
- Search engines
- Information Retrieval (IR)

---

## 🚀 Key Insight

Porter Stemmer prioritizes **speed over accuracy**, making it ideal for large-scale text processing.
